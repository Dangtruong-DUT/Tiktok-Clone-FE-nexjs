## Purpose of Use

The ViHSD dataset is used in this project strictly for **research and development purposes**.
Specifically, the dataset is utilized to:

- Train and evaluate machine learning and deep learning models for hate speech detection
- Experiment with various architectures such as CNN, RNN (GRU), and Transformer-based models
- Develop and improve an AI service module capable of detecting toxic, offensive, and hate speech content in Vietnamese

The resulting models are intended to be integrated into an internal AI service module to support content moderation and text classification tasks.
