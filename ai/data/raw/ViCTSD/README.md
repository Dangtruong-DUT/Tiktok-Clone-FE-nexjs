## Purpose of Use

The UIT-ViCTSD dataset is used in this project strictly for **research and development purposes**.
Specifically, the dataset is utilized to:

- Train and evaluate machine learning and deep learning models for constructive and toxic speech detection
- Experiment with various approaches including traditional Machine Learning, Deep Neural Networks, and Transformer-based models (e.g., PhoBERT)
- Develop and improve an AI service module capable of analyzing and classifying Vietnamese social media comments in terms of constructiveness and toxicity

The resulting models are intended to be integrated into an internal AI service module to support content moderation and text classification tasks.
